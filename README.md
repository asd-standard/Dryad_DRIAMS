# Dryad_DRIAMS

Sphinx documentation for the federated AMR analysis on the DRIAMS dataset.
Sources live in `docs/`; the rendered site is published at
<https://asd-standard.github.io/Dryad_DRIAMS/>.

```bash
make -C docs html     # build into docs/_build/html
make -C docs deploy   # build + force-push to the gh-pages branch
```
