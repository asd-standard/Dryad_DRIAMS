01 — Logistic Regression Analysis

Aggregated DRIAMS (A+B+C+D) — Top 3 drugs.

Objective

Baseline AMR prediction using logistic regression on pooled hospital data, establishing the simplest model against which all subsequent analyses are compared.

Approaches

Three variants are evaluated:

A) Raw LR

Vanilla LogisticRegression (scikit-learn) with no regularisation and default threshold of 0.5.

B) L2 LR + Threshold Tuning

LogisticRegression(C=1.0, penalty=’l2’) with Threshold Tuning via cross-validation to maximise worst-site Balanced Accuracy.

C) PCA + L2 LR + Threshold Tuning

Dimensionality reduction via PCA (retaining 95% variance) followed by L2 regularization LR with Threshold Tuning. Evaluates whether denoising spectra improves generalisation.

Preprocessing

  • log1p transform (stabilise variance)

  • Standardize to zero mean (fit on train only)

Train/Test Split

  • Species-stratified 70/15/15 — species-stratified split

  • Ensures no species appears in both train and test, forcing the model to generalise across species rather than memorising species-specific spectral features.

Key Findings

  • L2 regularization consistently outperforms raw LR

  • PCA degrades performance — the full 6000-bin spectrum contains useful information that PCA discards

  • Threshold Tuning provides a modest improvement over the default threshold

  • Serves as the linear baseline for all subsequent models
