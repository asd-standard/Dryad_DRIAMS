Introduction

This project predicts antimicrobial resistance (AMR) directly from MALDI-TOF mass spectra collected at four Swiss hospital sites (DRIAMS A/B/C/D). It starts from per-drug linear baselines and builds towards Federated learning with Flower (flwr): each hospital keeps its spectra private and only model updates are shared.

Motivation

  • MALDI-TOF is already routine in clinical microbiology for species identification; the same spectra carry resistance information.

  • Hospitals cannot pool patient data (privacy, regulation), which is why the project culminates in Federated learning.

  • A model that generalises across sites must survive Domain shift — different instruments, patient populations, and bacterial ecology — which is quantified by Cross-site evaluation.

At a Glance

Task

Binary resistant / susceptible prediction per drug from 6000-bin spectra

Data

DRIAMS A/B/C/D — 4 Swiss hospitals, 97 processed drug–site combinations

Models

LogisticRegression, MLP, Random Forest, Multi-label classification shared backbone

Metrics

Balanced Accuracy, AUC-ROC

Federated stack

Flower (flwr) with FedAvg, FedProx, FedLR, FedRF

Data preparation

Data Processing — process_driams.py → per-drug data.csv

End-to-End Pipeline

Dryad DRIAMS archives (raw/, preprocessed/, binned_6000/, id/)
     │
     │  process_driams.py — S/R filtering (S ≥ 500, R ≥ 10)
     ▼
Processed/Proc_DRIAMS-{A,B,C,D}/{drug}/data.csv
     │
     │  per-notebook preprocessing: log1p + standardize (fit on train only)
     ▼
Analyses 01–08 (LR / MLP / RF, multi-label, cross-site, federated)
