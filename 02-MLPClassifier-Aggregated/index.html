02 — MLP Classifier Analysis

Aggregated DRIAMS (A+B+C+D) — Top 3 drugs.

Objective

Replace the linear LogisticRegression baseline (see 01) with a non-linear MLP, evaluating whether deep learning extracts richer information from MALDI-TOF spectra.

  • MLP Architecture

Approaches

Three MLP variants, all using MaldiDeepKit’s MaldiMLPClassifier:

A) Baseline MLP

Standard MLP with BatchNorm and ReLU activations. No Dropout, no attention. Fixed default threshold 0.5.

B) Regularised MLP + Threshold Tuning

Adds Dropout regularisation. Threshold Tuning applied per-site via cross-validation to maximise worst-site Balanced Accuracy.

C) Attention MLP + Threshold Tuning

sigmoid-gated attention mechanism on the 512-dimensional hidden layer, allowing the model to dynamically weight spectral regions. Threshold Tuning applied as in B.

Preprocessing

Same as 01: log1p transform + Standardize to zero mean.

Key Findings

  • MLP consistently outperforms LR across all three drugs

  • Attention yields a small but consistent improvement over regularised MLP

  • Threshold tuning is critical for imbalanced resistance labels

  • Establishes the non-linear baseline and architecture used throughout the rest of the project
